## 🚀 Key Features

- **Interactive Animations**: Powered by Framer Motion and GSAP for micro-interactions and smooth page transitions.
- **Creative Gallery**: Filterable showcase of Brand Identity, Logos, Mockups, and Posters.
- **Dual Themes**: Full dark and light theme support with `next-themes`.
- **Responsive Architecture**: Pixel-perfect responsive layout across mobile, tablet, and ultra-wide desktops.
- **Interactive Contact Form**: Client-side validated contact form powered by Web3Forms.

## 💻 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Priya-584/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Static Export

```bash
npm run build
```

The static output is generated in the `out/` directory.
